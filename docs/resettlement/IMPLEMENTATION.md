# Доработка формы черновика

Frontend использует существующие маршруты проектов, договоров и создания дела. Пользователь выбирает ЖК и карточку жителя, отмечает квартиры и задаёт дополнительную компенсацию в процентах или квадратных метрах. В черновик передаются только выбранные строки. Совпадающие имена сохраняются как отдельные карточки с разными ID.

Расчёт формы использует сотые доли м² и центы. Цена единая для черновика, поскольку существующий API принимает одно поле `price_per_m2_minor`. Предварительный график на backend теперь вычисляет стоимость через целочисленное округление.

Текущая форма рассчитана на квартиры, уже связанные с договором выбранного жителя. Недостающая площадь блокирует отправку до появления механизма документированного урегулирования. Полная поддержка свободных квартир, отдельных цен, денежной компенсации, документов, слияния клиентов, расширенного реестра и интеграций входит в оставшиеся этапы ТЗ.
