# Результаты первого этапа доработки

- Backend, целевой тест API переселения — 12 из 12. Включены нулевая стоимость, 35,02 м² по 400 USD/м², округление половины цента и перенос платежа на последний день февраля.
- Frontend, целевой сценарий — 1 из 1. Используются синтетические договоры. Проверяется, что третья квартира не попадает в черновик и что платная площадь составляет 21,24 м².
- Сборка frontend Vite прошла. Сборка вывела предупреждение о размере отдельных файлов.
- Общий прогон frontend с jsdom — 428 прошли, 28 не прошли, отдельно зафиксирована одна ошибка окружения. Исходная ревизия в том же окружении — 426 прошли, 29 не прошли.
- Общий прогон backend выявил ошибки в тестах автоматизации продаж и миграций. Тестовая среда PostgreSQL и полная проверка RLS на синтетических данных для v2 не подтверждены.
- Production-деплой доработки отсутствует. Миграции на целевой базе не выполнялись.

## Соглашения

В изолированном PGlite проверены историческая дата, повтор запроса, конфликт реквизитов, запись дополнения, запрет записи в утверждённое дело и ограничения SQL-ролей. Целевой набор backend — 13 из 13, frontend — 1 из 1. Сборка frontend прошла.
