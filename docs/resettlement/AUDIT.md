## Ограничения для выпуска

- Проверить определения RPC, RLS, приватное хранилище документов и проектные полномочия по целевой схеме. Для нового поиска требуется серверное ограничение по доступным проектам и возврат минимального набора данных.
- Резервная копия базы и проверка существующих дел №1 и №3 требуют отдельного этапа перед миграциями. Разработка выполнялась без изменений реальных записей.
- Нужны интеграционные проверки утверждения, связанных ПКО и РКО, взаимозачёта, графиков, объединения клиентов и отката на синтетических данных.


## Проверка production-схемы Supabase

- Дела №1 и №3 находятся в статусе `APPROVED`. Проверка ограничилась чтением статуса.
- На таблицах модуля переселения включён RLS, явных политик нет. У `anon` и `authenticated` нет прав вызова основных RPC переселения и `update_income_payment_atomic`.
- В связанном наборе `leads`, `deals`, `payments`, `deal_payment_schedules`, `users`, `projects`, `units` RLS выключен, а обе роли имеют табличные права, включая SELECT. На уровне PostgreSQL у ролей есть USAGE на public. Проверка фактической доступности через Data API не проводилась. Перед изменением грантов нужно проверить зависимости старых клиентов и учётные данные, используемые штатным `getDB()`.
- Кроме `leads.interested_project_id` и `resettlement_cases.project_id`, проверка колонок `users`, `projects`, `leads`, `deals` и `resettlement_cases` не обнаружила полей проекта или организации. Серверная модель доступа по ЖК требует проверки дополнительных таблиц и настроек доступа.
- Действующий SQL черновика содержит защиту `DIFFERENT_BUYERS`.
- Внешние ключи на `leads` обнаружены в договорах, задачах, заметках и истории лида, заявках CRM, документах личности, Instagram, SMS, аудитах паспорта и таблицах кабинета покупателя. У кабинета покупателя есть отдельные ссылки владельца и участника. Процедура объединения должна проверять права доступа и конфликты по каждой связи, включая ограничения уникальности. Исторические журналы требуют отдельного правила сохранения авторства и исходных идентификаторов.
