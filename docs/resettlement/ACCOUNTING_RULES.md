# Учётные правила v2

Бесплатная площадь равна площади старого жилья плюс согласованная дополнительная площадь. Платная площадь равна положительной разнице между выделенной и бесплатной площадями. При недостающей площади текущая форма блокирует отправку. В полном сценарии требуется документированное решение руководителя.

Черновик текущей формы использует единую цену. Целевой расчёт при разных ценах должен суммировать округлённые суммы по квартирам. Физическая площадь квартиры берётся из каталога и учитывается полностью.

Целевая задолженность равна утверждённой стоимости за вычетом действительных зачтённых оплат и утверждённых взаимозачётов, ещё не учтённых в оплатах. Выплата по РКО сама по себе не погашает задолженность. Повторный взнос по ПКО учитывается как платёж один раз. Безденежный взаимозачёт требует отдельного основания и не формирует движение наличных. Первоначальный взнос, уже проведённый через ПКО, входит в сумму фактических оплат один раз. Переплата отражается отдельно.

До реализации денежной части эта документация фиксирует целевые правила. Текущая карточка показывает предварительный остаток по стандартным действительным платежам в USD.
